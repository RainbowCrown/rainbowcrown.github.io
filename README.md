# Guanhong Chen - Personal Website

A static multi-page academic website designed for GitHub Pages.

## Pages

- `index.html`: profile and selected highlights
- `research/`: research projects, publications, and patent
- `cv/`: web CV and PDF download
- `blog/`: article index
- `blog/welcome/`: example article page

## Publish with GitHub Pages

1. Create a public repository named `<your-github-username>.github.io`.
2. Upload everything inside this `personal-website` folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, then select `main` and `/(root)`.
5. Visit `https://<your-github-username>.github.io` after deployment finishes.

## Customize

- Replace the `GC` monogram in `index.html` with an `<img>` element when a portrait is available.
- Add new blog posts as `blog/article-name/index.html`, then add the post to `blog/index.html`.
- Keep `assets/Guanhong_Chen_CV.pdf` updated when the CV changes.
